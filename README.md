# 🥔 土豆 AI 启动器

基于 `llama.cpp` 打造的 Windows 本地全能 AI 轻服务器，一键启动，开箱即用。

官网：[https://potato-ai.pages.dev/](https://potato-ai.pages.dev/)

> **本软件的Git仓库仅有源码Batch文件。模型和llama依赖都嵌入在官网里的发行版。**

## 版本说明

- **本软件的 `qwen_in` 版本**：已内置 `Qwen2.5-7B-Instruct-Q4_K_M.gguf` 模型，开箱即用。
- **模型下载**：如您想下载其他模型，建议前往 [HF-Mirror](https://hf-mirror.com/) 进行下载（**强烈建议普通电脑用户直接使用`qwen_in` 版本的内置模型，省时省力**）。

## 核心特性

- **全硬件平台支持**：自动检测并适配 `NVIDIA (CUDA)`、`Intel (SYCL)`、`通用 (Vulkan)` 以及 `CPU (AVX2)` 运算引擎。
- **全能服务集成**：启动后自动提供 **Web 页面聊天服务** 与 **标准 OpenAI 兼容 API**。
- **纯净绿色**：完全基于 `llama.cpp` 和 Windows 批处理（Batch）构建，无需安装 Python 或 WSL，解压即用。
- **内置qwen模型仅供聊天使用，编程能力极差！**

## 配置要求

#### 最低配置（仅能跑起来，速度较慢，不建议日常使用）

- **CPU**：4 核以上，支持 AVX2 指令集
- **内存**：8GB（建议 16GB 以上）
- **存储**：20GB 以上可用空间
- **GPU（可选）**：Intel Arc 或更新架构的核显/独显，至少 4GB 可用显存（共享内存）

> ⚠️ **防劝退提示**：虽然上述配置门槛在今天的电脑中非常亲民，但如果您使用纯 CPU 模式或低端 GPU 运行 7B 模型，生成速度会慢得离谱，仅建议用来测试功能。**想要获得流畅的对话体验，强烈建议使用带有 4GB 以上独立显卡（或高性能核显）并开启硬件加速。**

## 快速上手

1. 去[官网](https://potato-ai.pages.dev/)下载已构建版本。

2. 解压本软件到一个**纯英文路径**下（如 `D:\PotatoAI`）。

3. 双击运行 `Potato_AI.exe`。

4. 根据终端提示，选择你想运行的模型序号。

5. 启动成功后，在浏览器访问：`http://127.0.0.1:8089/` 

6. 使用 OpenAI 兼容客户端时，API 地址填：`http://127.0.0.1:8089/v1`（API Key 随意填）。

## ❓ 常见问题 (FAQ)

**1. 启动时提示缺少 DLL 或闪退？**
请确保你没有直接把 `run.bat` 单独拎出来，它必须和 `engines` 文件夹在同一个目录下。如果仍有问题，请安装最新的显卡驱动。

**2. 怎么让局域网内的手机或平板用上这个 AI？**
确保手机和电脑连在同一个 Wi-Fi 下。在电脑上按 `Win + R` 输入 `cmd`，输入 `ipconfig` 找到你的 IPv4 地址（例如 `192.168.1.100`）。
然后在手机浏览器输入 `http://192.168.1.100:8089/` 即可访问。
*注意：如果电脑开启了防火墙，第一次访问可能会弹窗提示，请点击“允许访问”。*

**3. 杀毒软件报毒怎么办？**
本软件使用打包工具将批处理脚本封装成了 `.exe`，部分杀毒软件（如 360、Windows Defender）可能会误报。这是正常现象，请添加信任运行。
